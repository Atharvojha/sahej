# Sahej — Care that stays with you

An illustrated, interactive presentation of Sahej, a chronic-care follow-up concept for India. Includes the patient journey, market research, competitor landscape, SWOT analysis and Porter's Five Forces.

The patient journey runs entirely through native scrolling: today’s care, a labelled rewind, then the proposed experience with Sahej. It reverses when scrolling upward and remains scroll-driven on phone and landscape layouts. Reduced-motion preferences remove easing while retaining scroll progression.

**Website:** https://atharvojha.github.io/sahej/

## Files

- `index.html` — complete static website, including styles, scripts and SVG illustrations.
- `Sahej-research-report.pdf` — supplied research report linked by the website.
- `.github/workflows/pages.yml` — publishes the website to GitHub Pages when `main` changes.

## Update the website

Edit `index.html` and push to `main`. GitHub Actions publishes the update automatically. No build tools or package installation are required.

## Preview locally

From this directory, run `python3 -m http.server 8000`, then open http://localhost:8000/.

## Research context

Market estimates and competitor positioning are research assumptions or qualitative judgments, as labelled on the website. The patient journey illustrates a proposed product experience; it does not establish clinical efficacy or product-market fit. Source references and the supplied report are available on the website.
